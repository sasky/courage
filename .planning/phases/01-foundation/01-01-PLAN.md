# Phase 01: Foundation - Plan 01

## Objective
Set up Ratatui dependencies, create TUI module structure, and add CLI flag to switch between Telegram and TUI modes.

## Context
@Cargo.toml - Current dependencies
@src/main.rs - Entry point to modify
@src/lib.rs - Module exports

## Tasks

### Task 1: Add TUI Dependencies
**Type:** modify
**Files:** `Cargo.toml`
**Action:** Add ratatui, crossterm, and clap (for CLI args) to dependencies
**Test:**
```bash
cargo check
```
**Verify:** Dependencies resolve without errors
- [ ] done

---

### Task 2: Create TUI Module Structure
**Type:** create
**Files:** 
- `src/tui/mod.rs`
- `src/tui/app.rs`

**Action:** 
- Create `src/tui/` directory
- Create `mod.rs` with module exports
- Create `app.rs` with `App` struct containing:
  - `running: bool` field
  - `new()` constructor
  - `quit()` method to set running = false

**Test:**
```bash
cargo test tui
```
**Verify:** Module compiles, basic struct tests pass
- [ ] done

---

### Task 3: Implement Terminal Setup/Teardown
**Type:** create
**Files:** `src/tui/terminal.rs`

**Action:** Create terminal management with:
- `init()` - Enable raw mode, enter alternate screen, create Terminal
- `restore()` - Disable raw mode, leave alternate screen
- Use crossterm backend

**Test:**
```rust
#[test]
fn test_terminal_init_restore() {
    // Test that init/restore don't panic
}
```
**Verify:** Terminal can be initialized and restored without leaving terminal in bad state
- [ ] done

---

### Task 4: Add CLI Argument Parsing
**Type:** modify
**Files:** `src/main.rs`, `src/config.rs`

**Action:**
- Add clap derive macros for CLI args
- Add `--tui` flag to launch TUI mode
- Default behavior remains Telegram bot

**Test:**
```bash
cargo run -- --help
cargo run -- --tui  # Should show TUI (empty for now)
```
**Verify:** `--help` shows tui option, `--tui` flag is recognized
- [ ] done

---

### Task 5: Implement Basic App Loop
**Type:** modify
**Files:** `src/tui/app.rs`, `src/main.rs`

**Action:**
- Add `run()` method to App that:
  - Initializes terminal
  - Loops while `running` is true
  - Handles 'q' key to quit
  - Restores terminal on exit
- Wire up TUI mode in main.rs

**Test:**
```bash
cargo run -- --tui
# Press 'q' to exit
```
**Verify:** App launches, shows blank screen, exits cleanly on 'q'
- [ ] done

---

### Task 6: Export TUI Module
**Type:** modify

**Action:** Add `pub mod tui;` to lib.rs exports

**Test:**

**Verify:** All modules compile, existing tests still pass
- [ ] done
